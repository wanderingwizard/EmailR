Free Hosting & Real Webhook Blueprint

How to host this app for $0 and connect real open pixels, reply webhooks, and call bookings later.

1. How to Host a Free Website ($0/mo)

  • GitHub Pages: Create a free GitHub account, create a repository, upload index.html, and enable Settings → Pages → Deploy from main branch. You get a free https://username.github.io/repo/ URL.
  • Cloudflare Pages or Vercel: Drag and drop or connect your repo for instant global HTTPS hosting on a free tier.
  • Custom Domain (Optional): Buy a .com domain (~$10–$12/yr) and point DNS records to your free host so your tracking pixel and reply addresses use your own domain.

2. Real Email Open Pixel Endpoint

When sending HTML outreach emails via an API or serverless function (e.g., Cloudflare Worker, Vercel Function, or Supabase Edge Function), append a unique 1x1 tracking pixel:

<img src="https://api.yourdomain.com/track/open?msg=MSG_10492" width="1" height="1" alt="" style="display:block;" />

Your endpoint logs the open timestamp + count in Postgres/Supabase and returns a 1x1 transparent GIF/PNG with Cache-Control: no-store. Note: Corporate mail scanners and Apple Mail Privacy can trigger automated pre-fetches.

3. Real Inbound Email Reply Webhook

Send emails using a provider with inbound reply routing (such as Resend, Postmark, or SendGrid Inbound Parse) with a Reply-To like reply+MSG_10492@inbound.yourdomain.com.

When the estimator hits Reply, the provider POSTs the sender, subject, and plain/HTML body to /webhooks/email-reply. Your backend matches MSG_10492, inserts into activities, updates stage to Replied, and cancels pending 4-day follow-up automation.

4. Real Call Booking Webhook (Cal.com / Calendly)

Include a scheduling link with the prospect's email prefilled (e.g., https://cal.com/yourname/vdc-scoping?email=dan@contractor.com). Configure a webhook subscription on BOOKING_CREATED / invitee.created pointing to /webhooks/call-booked to set call_scheduled_at and move the stage to Call Scheduled.
